# Migración E.MO.TI.VE

Proyecto de migración de la aplicación Laravel a **Next.js** (frontend) y **Python FastAPI** (backend).

## Estructura

```
migrations/
├── docs/                 # Toda la documentación (.md)
│   ├── README.md         # Índice de documentos
│   ├── MANUAL_LANZAMIENTO.md

│   └── ...
├── backend-api/          # API FastAPI
├── frontend/             # App Next.js
└── README.md             # Este archivo
```
